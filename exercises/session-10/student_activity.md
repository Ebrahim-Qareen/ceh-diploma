# Session 10 — Student Activity & Rubric (CAPSTONE)

## Activity: the defence-in-depth capstone
Assess the lab environment across every layer of the diploma and produce the capstone report — your graduation deliverable.

### Steps
1. **Evasion** — evade a lab IDS (Lab A); note which detection method each technique beats and what re-catches it.
2. **Wireless** — capture & crack a WPA2 handshake on your test AP (Lab B); state the passphrase/WPA3 fix.
3. **Emerging surface** — find an open bucket + a default-credentialed device (Lab C); one-line finding + fix each.
4. **Crypto** — use the three tools and audit a target's TLS/ciphers (Lab D); flag weak deployments.
5. **Capstone** — assess across all ten sessions; write the defence-in-depth report (attack narrative, findings by layer, what failed/held, prioritised remediation, detections).

## Rubric (100 pts)
| Criterion | Pts |
|---|---|
| IDS evasion demonstrated + method→blind-spot reasoning + what re-catches it | 12 |
| WPA2 handshake captured & cracked (own AP) + fix stated | 12 |
| Cloud/IoT findings (open bucket + default creds) with fixes | 12 |
| Crypto: three tools used + TLS/cipher audit with weak-crypto findings | 12 |
| Capstone: attack narrative chaining ≥3 sessions | 12 |
| Capstone: defence-in-depth analysis (what failed / what held per finding) | 15 |
| Capstone: prioritised, leverage-ranked remediation + detections | 13 |
| Report quality (portfolio-grade: clear, actionable, decision-maker ready) | 12 |

**Authorisation gate:** any attack shown against a non-lab / non-owned target (network, AP, cloud, device) scores 0 overall.
